pypufferblow.protocol module#

Wire format of the Pufferblow command/event protocol, version 1.

The server’s docs/protocol/v1/fixtures/*.json are the contract; tests/fixtures/protocol_v1 holds an identical copy that the test suite parses. Unknown frames resolve to None so a newer server can add frames without breaking an older SDK.

class pypufferblow.protocol.EventTracker[source]#

Bases: object

Skips duplicate events (by event id) and notices gaps.

Delivery is at-least-once and in order per channel within one server epoch. Sequence numbers are per channel; the epoch changes when the server restarts, so a new epoch means anything may have been missed.

exception pypufferblow.protocol.ProtocolError(code: str, message: str, *, retryable: bool = False, retry_after: float | None = None)[source]#

Bases: Exception

A command the server refused, or that never got an answer.

code is one of the server’s codes (PERMISSION_DENIED, RATE_LIMITED, …) or one of three raised locally: NOT_CONNECTED, DISCONNECTED and TIMEOUT. retryable means sending the same command again is safe; for message.create the repeated nonce makes sure the server never posts the message twice.
